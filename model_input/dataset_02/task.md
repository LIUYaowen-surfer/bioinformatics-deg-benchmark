# 任务草案：细胞系单一激素与溶剂对照

主任务：仅用 `use_primary=true` 的 4 列，比较 `E2` 与 `DMSO`，方向为 log2(E2 / DMSO)。可单独制定第二题：仅用 `use_secondary=true` 的 4 列，比较 `Dex` 与 `DMSO`，方向为 log2(Dex / DMSO)。每个条件各有两个来源记录中的重复编号。两个任务共享 DMSO 对照，不应当作完全独立的数据集拆分训练与测试。

范围仅为该细胞系的表达响应。不能单凭这些比较推出患者生存、体内子宫增生、受体共占位或两种激素的相互作用机制。

输入为本目录的 `counts.tsv.gz` 与 `samples.tsv`。矩阵第一列是 `gene_id`，其余列全部是未标准化计数。仅选取本题指定的样本；提交时记录实际采用的样本列。`samples.tsv` 已按矩阵顺序排列；仍须检验一一对应。
